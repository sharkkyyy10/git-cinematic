# Git-Cinematic: Build Plan

> Fly through your git history as a living 3D city.
> Owner: **Sharkkyyy10** · Repository: `github.com/Sharkkyyy10/git-cinematic` · Hosting: Cloudflare Workers Static Assets

This document is the single source of truth for building v1. Follow the phases in order. A phase is done only when every acceptance check in it passes and the work is committed.

---

## 0. Principles

1. **Zero running cost.** Heavy work runs on the user's machine (CLI), the user's browser (viewer) or the user's CI (Action). Our infrastructure serves static files only.
2. **Source code never leaves the user's machine.** The CLI uploads nothing. A city file contains paths, counts and scores, never file contents.
3. **Deterministic output.** The same repo at the same HEAD produces a byte-identical `city.bin`. All sorting is explicit; no `Math.random()` outside seeded generators.
4. **Small dependency surface.** Runtime dependencies: `three` (viewer) only. The CLI uses Node built-ins only.
5. **Every phase ships green.** `npm run check` passes before every commit. Never bypass hooks (`--no-verify` is forbidden).

## 3. Data pipeline (packages/core)

### 3.1 Ingest

Run one git process, stream its stdout, never buffer the whole log:

```
git -C <repo> log --reverse --no-merges -M --numstat -z \
  --format=%x1e%H%x1f%at%x1f%an%x1f%ae%x1f%s
```

- Records start with `\x1e`. Header fields are split by `\x1f`.
- With `-z`, a normal numstat entry is `added\tdeleted\tpath\0`. A rename entry is `added\tdeleted\t\0old\0new\0`. Binary files report `-\t-`; treat as 0 lines and set the binary flag.
- Track renames with a `Map<currentPath, fileId>` so history follows the file. A rename moves the id to the new path.
- Output: `CommitEvent { sha, time, authorIndex, subject, changes: { fileId, added, deleted }[] }`.
- Authors are keyed by lower-cased email; display name is the most recent name for that email.
- Options: `--since <date>`, `--max-commits <n>` (keep the newest n).
- Current LOC: `git ls-tree -r -l HEAD`, then `git cat-file --batch` for blobs ≤ 2 MB; count `\n`; a NUL byte in the first 8000 bytes marks the file binary. Files that no longer exist at HEAD have `loc = 0` and the `deleted` flag.

### 3.2 Metrics (per file)

| Metric | Definition |
|---|---|
| `loc` | Lines at HEAD (0 if deleted) |
| `locMax` | Max cumulative net lines over history (drives layout footprint) |
| `churn` | Number of non-mass commits touching the file |
| `fixes` | Number of non-mass fix commits touching the file |
| `authors` | Distinct authors who touched it |
| `centrality` | PageRank on the co-change graph, normalised to [0, 1] |

- **Mass commit:** touches more than 50 files. Excluded from churn, fixes and coupling (it's a reformat, a vendor drop or a bulk rename).
- **Fix commit:** subject matches `^(fix|hotfix|bugfix)(\(.+\))?!?:` (case-insensitive) **or** contains a whole word from `fix|fixes|fixed|bug|bugs|hotfix|regression|crash`.
- **Co-change graph:** for each non-mass commit touching n ≥ 2 files, add weight `1/(n-1)` to every pair. PageRank: damping 0.85, 30 iterations, dangling mass redistributed uniformly.
- **Hotspot score** (computed in the viewer): `norm(churn) × norm(loc)`, where `norm` is rank-percentile.

### 3.3 Time buckets

- `B = min(128, max(8, weeksSpanned))` equal-width buckets from first to last commit.
- Per file per bucket:
  - `height`: cumulative net lines at the end of the bucket, clamped to ≥ 0 and capped at 65535.
  - `heat`: `heat[t] = heat[t-1] × 0.85 + fixesInBucket[t]`, then divided by the global 95th percentile, clamped to [0, 1] and quantised to u16.
- Store `bucketStart[t]` as u32 unix seconds.

### 3.4 Eras (the film's chapters)

1. Commits per bucket form a series.
2. Binary segmentation on the mean (minimum segment of 3 buckets, at most 8 segments, split only when it reduces squared error by more than 15%).
3. Classify each segment:
   - fix ratio > 0.4 → `Fix wave`
   - activity > 1.5 × the median → `Expansion`
   - lines deleted > lines added → `Cleanup`
   - otherwise → `Steady build`
4. The title is `<Kind> · <top-level dir with most churn>`, for example `Expansion · packages/viewer`.

Titles are template-based and deterministic.

### 3.5 Layout

- Build a directory tree from **every path that ever existed** (deleted files included), so buildings never move during replay.
- File weight = `sqrt(max(locMax, 1)) + 1`. Directory weight = sum of its children.
- Squarified treemap (Bruls, Huizing, van Wijk). Children are sorted by weight descending, then path ascending.
- Streets: inset each directory rectangle by 4 / 2 / 1 / 0.5 units at depths 1 / 2 / 3 / 4+.
- Each building footprint is its cell shrunk by 15% around the centre.
- Normalise the city to a 1000 × 1000 square centred at the origin.

### 3.6 Demo city

`packages/core/src/demo.ts` contains a seeded generator (mulberry32, seed `0xC1714`) that simulates a ~2,400-file, 6-year monorepo:
- 12 authors who join and leave over time
- 3 hot districts with fix waves
- a large cleanup era
- one big rename

It feeds the same encoder, and its output is `packages/viewer/public/demo/city.bin`, which is committed. This is the landing-page city.

## 4. CLI (packages/cli)

```
git-cinematic analyze [repo=.] [-o .cinematic/city.bin] [--since 2023-01-01] [--max-commits 50000] [--max-files 20000]
git-cinematic view    [city=.cinematic/city.bin] [--port 4173] [--no-open]
git-cinematic --version | --help
```

- `analyze` prints a one-screen summary:
  - commits, files, authors and eras
  - the top 5 hotspots
  - output size and elapsed time
- `analyze` exit codes: 0 on success; 1 if the path isn't a git repo or the repo has no commits; 2 on bad arguments.
- `--max-files`: keep the files with the highest `locMax` and fold the rest into one `…/other` building per directory.
- `view` serves the viewer bundled inside the CLI package (`dist/viewer/`, copied in at build time) using `node:http`, at `/`, with the city at `/local/city.bin`. It opens the browser with `?src=/local/city.bin` unless `--no-open` is given. Bind to `127.0.0.1` only.
- Performance target: analyse a 50k-commit / 10k-file repo in under 20 s on a recent laptop.

## 5. City file format: `city.bin` v1

The file is gzip-compressed. After decompression, all integers are little-endian and every section starts on a 4-byte boundary.

**Header (40 bytes):**

| Offset | Type | Field |
|---|---|---|
| 0 | u8×4 | magic `GCTY` |
| 4 | u16 | version = 1 |
| 6 | u16 | flags (bit0: truncated by `--max-files`) |
| 8 | u32 | fileCount F |
| 12 | u32 | dirCount D |
| 16 | u32 | bucketCount B |
| 20 | u32 | authorCount A |
| 24 | u32 | eraCount E |
| 28 | u32 | stringBytes S |
| 32 | u32 | generatedAt (unix s) |
| 36 | u32 | reserved = 0 |

**Sections, in order:**

1. **Strings:** S bytes of UTF-8, entries separated by NUL. Order: `[0]` repo name, then F file paths, then D dir paths, then A author names, then E era titles. Readers index this table once.
2. **bucketStart:** u32 × B.
3. **Files:** F records of 40 bytes each:

   | Bytes | Fields |
   |---|---|
   | 0–15 | `x f32, z f32, w f32, d f32` |
   | 16–31 | `loc u32, locMax u32, churn u32, fixes u32` |
   | 32–35 | `centrality f32` |
   | 36–37 | `authors u16` |
   | 38–39 | `flags u16` (bit0 deleted, bit1 binary) |

4. **Dirs:** D records of 20 bytes each: `x f32, z f32, w f32, d f32, depth u16, pad u16`.
5. **Eras:** E records of 12 bytes each: `startBucket u32, endBucket u32, kind u32` (0 steady, 1 expansion, 2 fix wave, 3 cleanup).
6. **History:** u16 × F × B × 2, laid out as file-major then bucket, interleaved as `[height, heat]`.

**Decoder rules (`format.ts`, shared by the CLI and the viewer):**
- Validate the magic and version.
- Before allocating anything, check that the summed section sizes match the byte length.
- Reject any count above 200,000 files or 1,024 buckets.
- Reject files larger than 64 MB.
- Never trust string contents; the viewer renders strings with `textContent` only.

`docs/CITY_FORMAT.md` mirrors this section. Any format change bumps the version and adds a test.

## 6. Viewer (packages/viewer)

### 6.1 Loading

Resolve the source in this order:

1. `?src=<url>`: same origin, or `https:` only.
2. Path `/gh/<owner>/<repo>` loads `https://raw.githubusercontent.com/<owner>/<repo>/HEAD/.cinematic/city.bin`.
3. A file dropped on the page, or chosen from the Open button.
4. Default: `/demo/city.bin`.

Decompress with `DecompressionStream('gzip')`, decode, then build the scene. On failure, show a friendly panel with what went wrong and how to generate a city (`npx git-cinematic analyze`). Never leave a blank canvas.

### 6.2 Rendering

- **One `InstancedMesh`** of a unit box (pivot at the base) for all buildings. Per-instance attributes: `aFootprint (vec4 x,z,w,d)`, `aFile (float index)`, `aStatic (vec2 centrality, authors)`.
- **History on the GPU:**
  - Upload the history as a `DataTexture` (`RG16UI`, integer sampling) of width 2048, with texel index `file × B + bucket`.
  - The vertex shader reads the two neighbouring buckets with `texelFetch` and interpolates them by `fract(uTime)`.
  - Scrubbing the timeline changes only `uTime`: no per-frame CPU work and no buffer uploads.
- **Height:** `h = 2.0 + 14.0 × log2(1 + loc)`. A building with `loc == 0` at time t collapses to zero scale.
- **Look:**
  - Dark night palette, `FogExp2`, a faint ground grid and district plates (from Dirs) slightly raised and outlined.
  - The fragment shader procedurally draws a window grid whose brightness comes from centrality.
  - Heat drives an inferno-style emissive ramp. When heat is above 0.6, add an animated flicker (`fbm` noise on `uClock`) and send it to bloom.
  - Calm monoliths (centrality > 0.7 and heat < 0.1) get a cool rim light.
- **Embers (optional):** GPU points over the 200 hottest buildings.
- **Camera:** `OrbitControls` with damping and limits: you can't go under the ground or zoom out past 3× the city size.
- **Performance budget:** 20k buildings at 60 fps on integrated graphics at 1080p. Device pixel ratio is capped at 2. Bloom runs at half resolution.

### 6.3 Interaction and UI (plain DOM over the canvas)

- **Header:** wordmark, repo name, and Open / Share / Record buttons.
- **Timeline bar:**
  - play/pause, a scrubber and the current date
  - era chapter markers coloured by kind
  - speed control (0.5× / 1× / 2× / 4×)
- **Title cards:** when playback enters an era, show a 2.5 s card with the era's title and date range.
- **Hover:** tooltip with the file path.
- **Click:** a side panel with path, LOC, churn, fixes, authors, centrality and hotspot rank, plus a "Fly to" button.
- **Search:** `/` focuses fuzzy path search; Enter flies to the match.
- **Tour:** `T` plays a camera tour of the top 5 hotspots (eased splines, 4 s each).
- **Keyboard:** Space toggles play; ← / → step one bucket.
- **Record:** captures `canvas.captureStream(60)` with `MediaRecorder` (VP9 webm, falling back to VP8) during a full replay plus the tour, then downloads `git-cinematic-<repo>.webm`.
- **Share:** copies the current URL. For `/gh/` cities that's a permanent link.
- **Accessibility:** every control is keyboard reachable with visible focus; `prefers-reduced-motion` disables flicker and auto-tour.
- **`<title>`** is exactly `Git-Cinematic`, followed by ` · <repo>` once a city is loaded. The deploy smoke test relies on the `<title>Git-Cinematic` prefix in the HTML.

### 6.4 Viewer tests (Playwright, `e2e/viewer.spec.ts`)

Run against `vite preview`:

1. The demo loads, the canvas is non-blank (sample pixels, at least 5% non-background), and there are no console errors.
2. Scrubbing the timeline changes the rendered pixels.
3. A click on a building opens the panel with a path.
4. `/gh/does-not/exist` shows the friendly error panel, not a blank page (mock the network with `page.route`).
5. A corrupted file produces the error panel.

## 7. Edge worker and deploy

- `worker/index.js` (Appendix B) serves assets through the `ASSETS` binding and answers `/healthz` with `ok`. If an HTML request gets a 404, it falls back to `/index.html` so client-side routes like `/gh/owner/repo` work.
- Deploy with `scripts/deploy.sh` (Appendix A). It uses curl only and has no wrangler dependency:
  1. Verify the token (`/user/tokens/verify`, falling back to `/accounts/:id/tokens/verify`).
  2. Build the manifest. Each hash is the first 32 hex characters of `sha256(base64(content) + extension)`.
  3. `POST …/workers/scripts/:name/assets-upload-session`.
  4. Upload each requested bucket to `…/workers/assets/upload?base64=true` with the session token, one multipart field per hash, each carrying its MIME type. Keep the completion token.
  5. `PUT …/workers/scripts/:name` with `metadata` (`main_module: worker.js`, an `assets` binding, the completion token, `not_found_handling: single-page-application`) and the module part.
  6. Enable the workers.dev route, look up the account subdomain, and smoke-test `/`, `/healthz`, an SPA route and `/demo/city.bin`.
- Required environment (never committed, loaded from `.env` by the caller):

  ```
  CLOUDFLARE_API_TOKEN   # custom token: Account › Workers Scripts › Edit
  CLOUDFLARE_ACCOUNT_ID
  ```

- Re-deploys only upload changed files, because the server returns only the missing hashes.
- The scripts have been verified against a mock of these endpoints. They cover:
  - a first upload, a cached re-deploy and a single-file change
  - a bad token, missing env and a missing asset directory
  - the content type of every multipart part

## 8. GitHub publishing and commit policy

- **Identity:** every commit is authored and committed as `Sharkkyyy10 <ID+Sharkkyyy10@users.noreply.github.com>`. The ID comes from `GET /user`; `scripts/publish-github.sh` sets it in the repo-local git config.
- **Single-author history:** no `Co-Authored-By` trailers and no tool attribution in commit messages, PR text or files. This is enforced by `scripts/hooks/commit-msg`, which `git config core.hooksPath scripts/hooks` activates.
- **Local term list:** the hooks also reject any term listed in `.git/info/blocked-terms`, a local, uncommitted file with one term per line.
- **Secrets:** `scripts/hooks/pre-commit` blocks `.env*`, GitHub tokens and private keys.
- **Commit messages:** Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`, `test:`, `perf:`, `refactor:`, `ci:`). Use the imperative mood, a subject of 72 characters or fewer, and a body explaining *why* when it isn't obvious.
- **Granularity:** at least one commit per phase. Split a phase into logical commits where natural (for example *ingest parser* and *rename tracking* as separate commits).
- **Publishing:** `scripts/publish-github.sh` creates `Sharkkyyy10/git-cinematic` if it doesn't exist, refuses to push if the history contains any other identity or co-author trailer, and pushes over HTTPS with a header, so the token is never stored in `.git/config`.
- **CI:** `.github/workflows/ci.yml` runs `npm ci && npx playwright install --with-deps chromium && npm run check` on push and PR (ubuntu-latest, Node 20).

## Appendix A: Deploy and publish scripts (use verbatim)

### `scripts/deploy.sh`

```bash
#!/usr/bin/env bash
# Deploy the built viewer to Cloudflare Workers Static Assets using curl only.
#
# Usage:  scripts/deploy.sh [assetDir] [--dry-run]
# Env:    CLOUDFLARE_API_TOKEN  (Account > Workers Scripts > Edit)
#         CLOUDFLARE_ACCOUNT_ID
#         CF_WORKER_NAME        (default: git-cinematic)
#         CF_COMPAT_DATE        (default: 2026-11-01)
#         CF_API_BASE           (default: https://api.cloudflare.com/client/v4; override for tests)
#         CF_SMOKE_URL          (optional; skip subdomain lookup and smoke-test this URL)
set -euo pipefail

ASSET_DIR="packages/viewer/dist"
DRY_RUN=0
for arg in "$@"; do
  case "$arg" in
    --dry-run) DRY_RUN=1 ;;
    *) ASSET_DIR="$arg" ;;
  esac
done

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
HELPER="$ROOT/scripts/cf-assets.mjs"
WORKER_FILE="$ROOT/worker/index.js"
API="${CF_API_BASE:-https://api.cloudflare.com/client/v4}"
NAME="${CF_WORKER_NAME:-git-cinematic}"
COMPAT="${CF_COMPAT_DATE:-2026-11-01}"

log() { printf '\033[1;36m▸\033[0m %s\n' "$*"; }
die() { printf '\033[1;31m✖\033[0m %s\n' "$*" >&2; exit 1; }

for bin in curl node; do command -v "$bin" >/dev/null || die "$bin is required"; done
[[ -d "$ASSET_DIR" ]] || die "asset dir '$ASSET_DIR' not found (run npm run build first)"
[[ -f "$WORKER_FILE" ]] || die "worker/index.js missing"

WORK="$(mktemp -d)"
trap 'rm -rf "$WORK"' EXIT

COUNT="$(node "$HELPER" manifest "$ASSET_DIR" "$WORK")"
log "manifest: $COUNT files from $ASSET_DIR"

if [[ "$DRY_RUN" == 1 ]]; then
  node "$HELPER" metadata "dry-run" "$COMPAT" "$WORK/metadata.json"
  log "dry run OK (manifest + metadata built, nothing uploaded)"
  exit 0
fi

: "${CLOUDFLARE_API_TOKEN:?CLOUDFLARE_API_TOKEN is not set}"
: "${CLOUDFLARE_ACCOUNT_ID:?CLOUDFLARE_ACCOUNT_ID is not set}"
ACC="$API/accounts/$CLOUDFLARE_ACCOUNT_ID"

# cf <out-file> <expected-codes-regex> <curl args...>
cf() {
  local out="$1" expect="$2"; shift 2
  local code
  code="$(curl -sS --retry 3 --retry-delay 2 -o "$out" -w '%{http_code}' "$@")" || die "network error calling Cloudflare"
  [[ "$code" =~ ^($expect)$ ]] || { node "$HELPER" check "$out" "HTTP $code" 2>&1 >&2 || true; die "unexpected HTTP $code"; }
}

AUTH=(-H "Authorization: Bearer $CLOUDFLARE_API_TOKEN")

log "verifying API token"
cf "$WORK/verify.json" "200|401|403" "${AUTH[@]}" "$API/user/tokens/verify"
if ! node "$HELPER" check "$WORK/verify.json" "token verify" 2>/dev/null; then
  # Account-owned tokens verify on the account endpoint.
  cf "$WORK/verify.json" "200" "${AUTH[@]}" "$ACC/tokens/verify"
  node "$HELPER" check "$WORK/verify.json" "token verify"
fi

log "opening asset upload session"
cf "$WORK/session.json" "200|201" "${AUTH[@]}" -H "Content-Type: application/json" \
  -X POST --data-binary "@$WORK/manifest-body.json" \
  "$ACC/workers/scripts/$NAME/assets-upload-session"
node "$HELPER" check "$WORK/session.json" "upload session"
UPLOAD_JWT="$(node "$HELPER" get "$WORK/session.json" result.jwt)" || die "no upload token returned"
COMPLETION_JWT="$UPLOAD_JWT"

node "$HELPER" buckets "$WORK/session.json" "$WORK" > "$WORK/buckets.txt"
BUCKETS="$(wc -l < "$WORK/buckets.txt" | tr -d ' ')"
if [[ "$BUCKETS" == 0 ]]; then
  log "all assets already uploaded"
else
  i=0
  while read -r line; do
    i=$((i + 1))
    form=()
    for pair in $line; do
      hash="${pair%%|*}"; mime="${pair#*|}"
      form+=(-F "$hash=<$WORK/b64/$hash.b64;type=$mime")
    done
    log "uploading bucket $i/$BUCKETS ($(( ${#form[@]} / 2 )) files)"
    cf "$WORK/upload.json" "200|201" -H "Authorization: Bearer $UPLOAD_JWT" -X POST "${form[@]}" \
      "$ACC/workers/assets/upload?base64=true"
    node "$HELPER" check "$WORK/upload.json" "asset upload"
    if jwt="$(node "$HELPER" get "$WORK/upload.json" result.jwt)"; then COMPLETION_JWT="$jwt"; fi
  done < "$WORK/buckets.txt"
  [[ "$COMPLETION_JWT" != "$UPLOAD_JWT" ]] || die "upload finished without a completion token"
fi

log "deploying worker '$NAME'"
node "$HELPER" metadata "$COMPLETION_JWT" "$COMPAT" "$WORK/metadata.json"
cf "$WORK/script.json" "200|201" "${AUTH[@]}" -X PUT \
  -F "metadata=@$WORK/metadata.json;type=application/json" \
  -F "worker.js=@$WORKER_FILE;filename=worker.js;type=application/javascript+module" \
  "$ACC/workers/scripts/$NAME"
node "$HELPER" check "$WORK/script.json" "script deploy"

if [[ -n "${CF_SMOKE_URL:-}" ]]; then
  URL="${CF_SMOKE_URL%/}"
else
  log "enabling workers.dev route"
```

### `scripts/cf-assets.mjs`

```js
#!/usr/bin/env node
// Helper for scripts/deploy.sh. All HTTP happens in curl; this file only
// hashes files, writes request bodies and reads JSON responses.
//
//   node scripts/cf-assets.mjs manifest <assetDir> <workDir>
//   node scripts/cf-assets.mjs check    <response.json> <label>
//   node scripts/cf-assets.mjs get      <response.json> <dot.path>
//   node scripts/cf-assets.mjs buckets  <response.json> <workDir>
//   node scripts/cf-assets.mjs metadata <completionJwt> <compatDate> <out.json>
import { createHash } from "node:crypto";
import { mkdirSync, readdirSync, readFileSync, statSync, writeFileSync } from "node:fs";
import { extname, join, relative, sep } from "node:path";

const MIME = {
  html: "text/html",
  js: "text/javascript",
  mjs: "text/javascript",
  css: "text/css",
  json: "application/json",
  svg: "image/svg+xml",
  png: "image/png",
  jpg: "image/jpeg",
  jpeg: "image/jpeg",
  webp: "image/webp",
  ico: "image/x-icon",
  woff2: "font/woff2",
  wasm: "application/wasm",
  txt: "text/plain",
  webmanifest: "application/manifest+json",
  bin: "application/octet-stream",
  map: "application/json",
};

const MAX_FILE_BYTES = 25 * 1024 * 1024;

function fail(msg) {
  process.stderr.write(`error: ${msg}\n`);
  process.exit(1);
}

function walk(dir) {
  const out = [];
  for (const name of readdirSync(dir).sort()) {
    const full = join(dir, name);
    const st = statSync(full);
    if (st.isDirectory()) out.push(...walk(full));
    else if (st.isFile()) out.push(full);
  }
  return out;
}

function readJson(file) {
  try {
    return JSON.parse(readFileSync(file, "utf8"));
  } catch {
    fail(`could not parse JSON response in ${file}`);
  }
}

const [cmd, ...args] = process.argv.slice(2);

switch (cmd) {
  case "manifest": {
    const [assetDir, workDir] = args;
    if (!assetDir || !workDir) fail("usage: manifest <assetDir> <workDir>");
    const files = walk(assetDir);
    if (files.length === 0) fail(`no files in ${assetDir}`);
    if (!files.some((f) => relative(assetDir, f) === "index.html")) fail(`${assetDir}/index.html missing`);
    mkdirSync(join(workDir, "b64"), { recursive: true });
    const manifest = {};
    const index = {};
    for (const file of files) {
      const bytes = readFileSync(file);
      if (bytes.length > MAX_FILE_BYTES) fail(`${file} exceeds 25 MiB`);
      const b64 = bytes.toString("base64");
      const ext = extname(file).slice(1).toLowerCase();
      const hash = createHash("sha256").update(b64 + ext).digest("hex").slice(0, 32);
      const key = `/${relative(assetDir, file).split(sep).join("/")}`;
      manifest[key] = { hash, size: bytes.length };
      index[hash] = { path: key, type: MIME[ext] ?? "application/octet-stream" };
      writeFileSync(join(workDir, "b64", `${hash}.b64`), b64);
    }
    writeFileSync(join(workDir, "manifest-body.json"), JSON.stringify({ manifest }));
    writeFileSync(join(workDir, "index.json"), JSON.stringify(index));
    process.stdout.write(`${files.length}\n`);
    break;
  }
  case "check": {
    const [file, label] = args;
    const body = readJson(file);
    if (body.success !== true) {
      const errs = (body.errors ?? []).map((e) => `${e.code}: ${e.message}`).join("; ");
      fail(`${label} failed${errs ? ` (${errs})` : ""}`);
    }
    break;
  }
  case "get": {
    const [file, path] = args;
    let v = readJson(file);
    for (const part of path.split(".")) v = v?.[part];
    if (v === undefined || v === null) process.exit(2);
    process.stdout.write(typeof v === "string" ? v : JSON.stringify(v));
    break;
  }
  case "buckets": {
    // One line per bucket: "hash|mime hash|mime ..."
    const [file, workDir] = args;
    const body = readJson(file);
    const index = JSON.parse(readFileSync(join(workDir, "index.json"), "utf8"));
    for (const bucket of body.result?.buckets ?? []) {
      const parts = bucket.map((h) => {
        if (!index[h]) fail(`server asked for unknown hash ${h}`);
        return `${h}|${index[h].type}`;
      });
      if (parts.length) process.stdout.write(`${parts.join(" ")}\n`);
    }
    break;
  }
  case "metadata": {
    const [jwt, compat, out] = args;
    if (!jwt || !compat || !out) fail("usage: metadata <jwt> <compatDate> <out.json>");
    const meta = {
      main_module: "worker.js",
      compatibility_date: compat,
      bindings: [{ type: "assets", name: "ASSETS" }],
      assets: {
        jwt,
        config: { html_handling: "auto-trailing-slash", not_found_handling: "single-page-application" },
      },
    };
    writeFileSync(out, JSON.stringify(meta));
    break;
  }
  default:
    fail("unknown command");
}
```

### `scripts/publish-github.sh`

```bash
#!/usr/bin/env bash
# Create (if needed) github.com/$GH_OWNER/$GH_REPO and push the current branch.
# Usage:  scripts/publish-github.sh
# Env:    GITHUB_TOKEN  (classic: public_repo scope; or taken from `gh auth token`)
#         GH_OWNER      (default: Sharkkyyy10)
#         GH_REPO       (default: git-cinematic)
#         GH_PRIVATE    (default: false)
#         GH_API_BASE   (default: https://api.github.com; override for tests)
#         GIT_REMOTE_URL(default: https://github.com/$GH_OWNER/$GH_REPO.git; override for tests)
set -euo pipefail

OWNER="${GH_OWNER:-Sharkkyyy10}"
REPO="${GH_REPO:-git-cinematic}"
PRIVATE="${GH_PRIVATE:-false}"
API="${GH_API_BASE:-https://api.github.com}"
REMOTE="${GIT_REMOTE_URL:-https://github.com/$OWNER/$REPO.git}"

log() { printf '\033[1;36m▸\033[0m %s\n' "$*"; }
die() { printf '\033[1;31m✖\033[0m %s\n' "$*" >&2; exit 1; }

if [[ -z "${GITHUB_TOKEN:-}" ]] && command -v gh >/dev/null && gh auth status >/dev/null 2>&1; then
  GITHUB_TOKEN="$(gh auth token)"
fi
: "${GITHUB_TOKEN:?set GITHUB_TOKEN or log in with gh}"

git rev-parse --is-inside-work-tree >/dev/null 2>&1 || die "not inside a git repository"
git rev-parse HEAD >/dev/null 2>&1 || die "no commits yet"

WORK="$(mktemp -d)"; trap 'rm -rf "$WORK"' EXIT
H=(-H "Authorization: Bearer $GITHUB_TOKEN" -H "Accept: application/vnd.github+json" -H "X-GitHub-Api-Version: 2022-11-28")

gh_api() { # gh_api <out> <curl args...>  -> prints HTTP code
  curl -sS -o "$1" -w '%{http_code}' "${H[@]}" "${@:2}" || die "network error calling GitHub"
}
field() { node -e 'const o=JSON.parse(require("fs").readFileSync(process.argv[1],"utf8"));const v=process.argv[2].split(".").reduce((a,k)=>a?.[k],o);if(v==null)process.exit(2);process.stdout.write(String(v))' "$1" "$2"; }

code="$(gh_api "$WORK/user.json" "$API/user")"
[[ "$code" == 200 ]] || die "token rejected by GitHub (HTTP $code)"
LOGIN="$(field "$WORK/user.json" login)"
[[ "$LOGIN" == "$OWNER" ]] || die "token belongs to '$LOGIN', expected '$OWNER'"

# Identity: every commit in this repo is authored and committed as the owner.
UID_="$(field "$WORK/user.json" id)"
EMAIL="${GIT_AUTHOR_EMAIL_OVERRIDE:-$UID_+$OWNER@users.noreply.github.com}"
git config user.name "$OWNER"
git config user.email "$EMAIL"

BAD="$(git log --format='%an <%ae>%n%cn <%ce>' | sort -u | grep -v -x "$OWNER <$EMAIL>" || true)"
if [[ -n "$BAD" ]]; then
  printf '%s\n' "$BAD" >&2
  die "history contains other identities (listed above); rewrite them before publishing"
fi
if git log --format=%B | grep -qi '^co-authored-by:'; then
  die "history contains Co-Authored-By trailers; remove them before publishing"
fi

code="$(gh_api "$WORK/repo.json" "$API/repos/$OWNER/$REPO")"
if [[ "$code" == 404 ]]; then
  log "creating $OWNER/$REPO"
  body="{\"name\":\"$REPO\",\"private\":$PRIVATE,\"description\":\"Fly through your git history as a living 3D city.\",\"has_wiki\":false}"
  code="$(gh_api "$WORK/create.json" -X POST --data "$body" "$API/user/repos")"
  [[ "$code" == 201 ]] || die "could not create repo (HTTP $code)"
elif [[ "$code" == 200 ]]; then
  log "$OWNER/$REPO already exists"
else
  die "could not read repo (HTTP $code)"
fi

if git remote get-url origin >/dev/null 2>&1; then git remote set-url origin "$REMOTE"; else git remote add origin "$REMOTE"; fi

BRANCH="$(git symbolic-ref --short HEAD)"
log "pushing $BRANCH"
BASIC="$(printf 'x-access-token:%s' "$GITHUB_TOKEN" | base64 | tr -d '\n')"
git -c "http.https://github.com/.extraheader=AUTHORIZATION: basic $BASIC" push -u origin "$BRANCH"

log "done: https://github.com/$OWNER/$REPO"
```

### `scripts/hooks/pre-commit`

```bash
#!/usr/bin/env bash
# Block secrets and locally blocked terms from entering history.
set -euo pipefail
git_dir="$(git rev-parse --git-dir)"

staged="$(git diff --cached --name-only --diff-filter=ACMR)"
[[ -z "$staged" ]] && exit 0

if echo "$staged" | grep -Eq '(^|/)\.env($|\.)'; then
  echo "pre-commit: refusing to commit .env files" >&2
  exit 1
fi

diff="$(git diff --cached -U0 --no-color | grep '^+' | grep -v '^+++' || true)"
if echo "$diff" | grep -Eq '(ghp_[A-Za-z0-9]{30,}|github_pat_[A-Za-z0-9_]{30,}|BEGIN [A-Z ]*PRIVATE KEY)'; then
  echo "pre-commit: staged changes look like they contain a secret" >&2
  exit 1
fi

list="$git_dir/info/blocked-terms"
if [[ -f "$list" ]]; then
  while IFS= read -r term; do
    [[ -z "$term" || "$term" == \#* ]] && continue
    if echo "$diff" | grep -qiF -- "$term" || echo "$staged" | grep -qiF -- "$term"; then
      echo "pre-commit: staged changes contain a blocked term (see .git/info/blocked-terms)" >&2
      exit 1
    fi
  done < "$list"
fi
```
